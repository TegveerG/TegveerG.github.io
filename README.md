# Project 1: Analyzing Inceptive Municipal Efforts to Achieve Carbon Neutrality by 2050 in Boston (89/100)

This research project for my GRS MA681 class in the R programming language aimed to analyze the significance of the changes in greenhouse gas (GHG) emissions generated by municipal operations in the City of Boston from the year 2005 to 2018. The City had pledged in the year 2000, when it enlisted itself in the Cities for Climate Protection Campaign of ICLEI (Local Governments for Sustainability) network, to take an active, leading role in advancing climate action. Therefore, a statistical examination of the local government’s progress of combating global warming helped me benchmark Boston government's successes against its claims laid out in chronological versions of the Climate Action Plan. To test these claims, the tools used were hypothesis testing, general linear models, including ANCOVA and an Autoregressive model, assuming an Autoregressive (Lag 1) correlation structure. 

My professor's comments about the project were particularly helpful to keep in mind key points for future projects, especially those that I shall go on to pursue at graduate school! A useful point he highlighted was that it would have been useful to see a more comprehensive model that accounts all of the variables, which would augment the separate ANCOVAs. I, indubitably, had ran a linear model with all my variables on my console, but did not include it in my report. Professor also indicated that there was not a lot of reason to think the data is stationary as is, so an AR model might not be appropriate.
